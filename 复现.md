## Table 3 最终版复现协议

### 1. 一条任务的标准启动模板

每次只改这 4 个变量：

```bash
TASK_ID=abide_age
FOLD=1
GPU=cuda:2
RUN_ROOT=outputs/${TASK_ID}_$(date +%Y%m%d_%H%M)
```

然后启动：

```bash
python launch_table3_queue.py \
  --config our_plan/table3_tasks.yaml \
  --task_ids "$TASK_ID" \
  --folds "$FOLD" \
  --seeds 1,2,3 \
  --device "$GPU" \
  --output_root "$RUN_ROOT"
```

### 2. 10 个任务的协议总表

| task_id | 任务 | fold | 指标 | 备注 |
| --- | --- | --- | --- | --- |
| `abide_age` | ABIDE age | `1` | `MSE / Pearson R` | 回归 |
| `nki_age` | NKI age | `1,2,3` | `MSE / Pearson R` | 回归 |
| `sald_age` | SALD age | `1,2,3` | `MSE / Pearson R` | 回归 |
| `abcd_sex` | ABCD sex | `1` | `ACC / F1` | 分类 |
| `hcp_sex` | HCP sex | `1` | `ACC / F1` | 分类 |
| `bhrc_sex` | BHRC sex | `1,2,3` | `ACC / F1` | 分类 |
| `ppmi_pd_diagnosis` | PPMI PD diagnosis | `1` | `ACC / F1` | 分类 |
| `adni_mci` | ADNI(MCI) | `1` | `ACC / F1` | 分类 |
| `adni_ad` | ADNI(AD) | `1` | `ACC / F1` | 分类 |
| `nki_education` | NKI education | `1` | `ACC / F1` | 分类 |

### 3. 看日志和结果

单个 run 的训练日志：

```bash
tail -f "$RUN_ROOT/$TASK_ID/fold1/seed1/train.log"
```

一个任务的所有 run 一次性看完：

```bash
grep -Hn -E 'Epoch|New best|Early stopping|Test metrics' \
  "$RUN_ROOT/$TASK_ID"/fold*/seed*/train.log
```

一个任务的最终结果汇总：

```bash
python summarize_table3.py --config our_plan/table3_tasks.yaml --output_root "$RUN_ROOT"
cat "$RUN_ROOT/table3_style_summary.csv"
```

如果要把 `outputs/` 下面 10 个任务一起汇总，就把 `--output_root` 改成 `outputs`。

### 4. 结果目录约定

- 每个任务一个目录：`outputs/<task_id>_<timestamp>/`
- 每个 run 一个子目录：`<task_root>/<task_id>/foldX/seedY/`
- `summarize_table3.py` 会自动读取每个任务最新的一次结果目录，并输出：
  - `task_summary.csv`
  - `table3_style_summary.csv`
